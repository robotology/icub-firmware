# host

The folder of the Dictionary of udpdemo-tether for `embot-tether`, the client of TETHER: run it from here, so that it
reads and writes `./dictionary.toml` (not committed: the first `embot-tether rpc` browses the board and writes it).

- install the tools, on Windows 11 or Ubuntu 24.04 / 26.04: `embot/svc/host/README.md`
- use `embot-tether` (the pages, the prompt and its local commands, the browse, the stream): `embot/svc/host/tether/README.md`
- only the commands, for this example: `../quick.startup.md`
